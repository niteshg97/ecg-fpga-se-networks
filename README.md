# Low-Latency Transformer Inference on FPGAs for Cardiac Anomaly Detection

Implementation of a hardware-aware SE-based ECG anomaly detection network deployed using hls4ml and Vivado HLS.

## Repository Structure

- notebook/ : Complete training and FPGA workflow
- figures/ : Paper figures
- hls_projects/ : Generated HLS projects
- model_weights/ : Trained model weights
- data/ : Experiment metrics and reported numbers
- paper/ : Research manuscript
